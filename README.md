# loguno-tools — Privacy Policy

loguno-tools is a personal tool used only by the owner of the YouTube channel it connects to.

What it accesses: YouTube channel data (videos, thumbnails, analytics) of the owner's own channel, through the YouTube Data API and YouTube Analytics/Reporting API, after the owner signs in with Google.

What it does with the data: shows statistics to the owner and updates the owner's own videos (titles, descriptions, thumbnails) at the owner's request.

What it does not do: it does not sell, share or transfer data to anyone; it has no other users; it does not use data for advertising.

Storage: access tokens and fetched data are stored only on the owner's computer. Access can be revoked at any time at https://myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Questions: open an issue in this repository.
